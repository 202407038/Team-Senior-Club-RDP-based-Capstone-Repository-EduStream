## 문서 운영 기준

- 루트 `README.md`는 프로젝트 입구 역할만 합니다.
- 현재 상태와 목표는 `work/STATUS_AND_ROADMAP.md`에서 관리합니다.
- 작업 방식과 PR 작성 방식은 `work/DEVELOPMENT_GUIDE.md`에서 관리합니다.
- 구조, 사용자 흐름, 작업 기록, 발표 자료는 `reference/`에 둡니다.
- 오래된 계획 문서는 삭제하지 않고 `archive/`에 보관합니다.
