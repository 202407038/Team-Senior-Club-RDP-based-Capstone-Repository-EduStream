## 2. 추가한 실패·복구 검증

- 같은 파일을 두 번 받아도 기존 파일을 보존하고 새 요청/파일명으로 저장하며, 교수자는 각 저장 완료를 확인합니다.
- 등록 후 길이는 같고 해시가 달라진 원본은 SourceChanged로 실패합니다. 저장 완료 ACK/완성 파일 없이 끝나고 해제·재등록 후 새 파일 ID로 성공합니다.
- 다운로드 디렉터리 자리에 일반 파일이 있으면 저장 오류를 반환하고 서버 요청을 정리합니다. 경로 문제를 해결한 뒤 새 요청으로 성공합니다. 실제 ACL 접근 거부 검증과는 다릅니다.
- 첫 청크가 실제 디스크에 쓰인 직후 취소하면 partial 파일을 지우고 성공 ACK 없이 끝납니다. 새 요청은 정상 저장됩니다.
- 서버 등록 해제가 학생 목록에 반영된 뒤 새 다운로드는 FileUnavailable로 거부됩니다. 이미 저장한 사본은 삭제하지 않습니다. 전송 도중 해제/권한 철회는 기존 서비스 회귀와 구분합니다.

파일: `FinalReadinessSecureContractTests.cs`, `SecureFileRoutingFailureTests.cs`.
파일 통합 테스트는 기존 `SecureFileRoutingWiringTests`의 실제 TLS/TCP 시험 환경을 공유합니다. 파일 본문·송수신·저장을 성공 대역으로 바꾸지 않습니다.
