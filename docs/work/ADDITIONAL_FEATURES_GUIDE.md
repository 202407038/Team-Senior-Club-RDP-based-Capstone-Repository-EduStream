# 추가 기능 사용 및 검증 안내

기준: 2026-11-05 추가 기능 소스 PR. 기존 실행용 ZIP에는 아래 변경이 모두 들어 있지 않습니다. [현재 상태](./STATUS_AND_ROADMAP.md)를 먼저 확인합니다.

## 참가와 명단

- 교수자가 세션을 열면 학생은 `교수자 자동 찾기`로 같은 LAN의 결과를 확인합니다. 여러 교수자가 있으면 원하는 결과를 선택합니다. 검색되지 않으면 교수자 화면의 IP를 직접 입력합니다. 기본 포트는 5000, 변경 시 고급 설정을 사용합니다.
- 자동 찾기는 비밀번호나 명단 대조를 생략하는 기능이 아닙니다. 방 비밀번호가 설정되어 있으면 입력해야 합니다.
- 교수자는 `엑셀 명단 미리보기`에서 명단을 읽어 오류를 확인하고, 세션을 열기 전에 대조 정책을 적용합니다. 실제 이름·전체 학번이 필요하며 마스킹 학번을 추측해서 채우지 않습니다. 학번은 앞자리 0을 보존할 수 있도록 텍스트로 관리합니다.
- 명단 대조를 켜면 이름·학번이 일치하지 않거나 동일 학생이 이미 참가한 경우 거부합니다. 명단 없이 참가하는 기존 방식도 유지합니다. 입력값 일치는 학교 계정 본인 인증이 아닙니다.
- 교수자 `출입 기록`에서 입퇴장 현황을 확인하고 CSV로 보관합니다. 실제 명단·학번·출입 CSV는 공개 저장소나 팜플렛에 넣지 않습니다. 명단/세션 상태의 영구 저장을 전제로 사용하지 말고 새 실행 시 적용 상태를 확인합니다.

## 채팅과 공지

- `대화 선택`에서 전체 또는 특정 학생/교수자 대화를 선택합니다. 개인 대화는 해당 상대에게만 전달합니다. 학생도 채팅 텍스트를 선택해 복사할 수 있습니다.
- 전체 채팅은 이름만 표시합니다. 다른 학생에게 발신자의 학번을 보내지 않으며, 이름이 같아도 내 메시지는 별도로 표시합니다.
- 일반 공지는 약 3초 뒤 배너가 사라지고 공지함에 남습니다. 중요 공지는 `확인`을 눌러 닫으며 공지함에서 다시 볼 수 있습니다. 중요 공지와 일반 공지는 강조를 구분합니다.
- 교수자는 공지의 수신·확인 현황을 볼 수 있습니다. 학생의 수신과 확인은 서로 다른 상태입니다.

## 강의 파일과 학생 제출

- 파일 선택/드롭은 먼저 선택만 준비합니다. `목록에 등록`을 눌러 세션에 게시한 뒤 학생이 필요한 파일을 다운로드합니다. 등록 해제는 목록에서 내리는 동작이며 이미 학생이 저장한 파일을 지우지 않습니다.
- 다운로드는 Windows 다운로드 폴더를 사용하고 동명 파일을 덮어쓰지 않습니다. 교수자 전송 완료와 학생의 디스크 저장 확인을 구분합니다.
- 교수자가 학생 파일 제출을 열면 학생은 파일을 골라 제출합니다. 전송 중 취소할 수 있으며 서버가 길이·해시를 확인하고 실제 저장한 결과로 완료를 표시합니다.
- 제출 파일은 교수자 문서 폴더 아래 `EduStream/학생제출`에 학생별로 보관합니다. 학번이 없는 경우 안전한 대체 폴더명을 사용합니다. 재제출은 기존 파일을 보존하며 앱 재시작 뒤 과거 접수 목록 전체를 자동 복원한다고 보장하지 않습니다.

## 화면과 테마

- 교수자 공유는 WDS(RDP)가 메인입니다. 참가 학생은 별도 초대 코드를 입력하지 않습니다. 학생 보기를 연다는 이유로 교수자 공유를 강제로 중지하지 않습니다.
- 교수자 창/학생 보기 창은 재공유 방지를 위한 캡처 제외가 적용됩니다. 일반 캡처에 창이 보이지 않을 수 있습니다. 이때 기능 화면을 합성해서 실제 수신 증거로 사용하지 않습니다.
- 해/달 버튼으로 옅은 오프화이트와 다크 테마를 바꿉니다. 학생의 채팅·파일 영역은 접었다 펼칠 수 있습니다. 공유 영상 자체의 색상은 테마에 맞춰 바꾸지 않습니다.
- 휠 확대·축소는 합의에 따라 제외했습니다. 한 Windows 로그인에서 동시 WDS 송신이 실패하는 조건은 별도 PC 양방향 인수와 구분합니다.

## 확인된 범위와 남은 검수

Release 빌드 경고/오류 0, 비화면 선별 회귀 968 통과/실패 0. native/창/입력 클래스 제외 필터를 사용했으므로 전체 실환경 결과가 아닙니다. 명단 32명은 순차 입장·퇴장 검증이며 동시 인원 보장이 아닙니다.

현장 사용자는 양방향 화면 공유·원격 제어·동시 접속을 확인했습니다. 자동 검사 결과나 최대 수용 인원과는 별개입니다. 다른 환경에서 문제가 생기면 버전, 교수자/학생 PC 구분, 재현 순서, 기대 결과와 실제 결과를 기록합니다. 원본 로그의 비밀번호·초대 비밀·개인정보는 공유하지 않습니다.
