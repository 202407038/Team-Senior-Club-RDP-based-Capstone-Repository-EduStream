# 통합 학생 목록 및 출입 기록

이 문서는 후속 소스 PR의 변경 사항입니다. 기존 `v1.0.0` ZIP에 이미 반영되었다는 뜻은 아닙니다.

## 사용 방법

1. 교수자 오른쪽 학생 목록의 `명단 관리`에서 학생명단 `.xlsx`를 가져옵니다. 오류 행은 목록에서 확인하며 입장 대조 설정은 세션을 닫은 상태에서 적용합니다.
2. 접속한 학생이 위로 올라오며 접속 그룹과 미접속 그룹 안에서는 학번의 숫자 순으로 정렬합니다. 학번 표시의 앞자리 0은 보존합니다. 숫자로 해석할 수 없는 학번은 해당 그룹의 숫자 학번 뒤에 배치합니다.
3. 접속한 학생의 이름을 누르면 화면을 펼칩니다. 다른 학생의 입퇴장으로 순서가 바뀌어도 기존 학생 행과 펼침 상태는 유지합니다. 퇴장한 학생의 화면은 접습니다.
4. 각 학생의 `기록` 버튼으로 입퇴장 기록을 따로 펼칩니다. 다른 학생의 기록을 열어도 먼저 연 기록은 닫히지 않습니다. 재입장하면 같은 학생 행에 기록을 추가합니다.
5. `명단 관리`의 `접속 기록 CSV 저장`으로 보관합니다. 새 세션에서는 이전 접속 기록이 초기화되므로 필요한 기록을 먼저 저장합니다.

## 간소화한 표시

세션/IP/명단 아래의 긴 상시 설명은 제거하고 세션 상태·명단 적용 결과·오류 같은 필요한 상태만 짧게 표시합니다. 자동 찾기 상태는 IP 새로고침 버튼의 툴팁에서 확인할 수 있습니다. 설명 제거는 비밀번호나 명단 대조 정책 제거가 아닙니다.

## 검증과 개인정보

- 합성 명단으로 접속 우선/숫자 학번 정렬, 행 객체 유지, 독립 기록 펼침, 재입장 누적, 잘못된 중복 행 및 명단 없는 참가를 검사합니다.
- 실제 로컬 TLS 접속·퇴장·재접속과 다음 명단 미리보기가 진행 중인 입장 대조 명단을 바꾸지 않는지 검사합니다.
- 로컬 실제 명단 확인 자료와 학번 정정 내역은 비공개로 보관하며 Git에는 넣지 않습니다. 공개 테스트에는 합성 학생과 임의 학번만 사용합니다.
- 접속 기록은 학교 본인 인증이나 자동 출석 인정 결과가 아닙니다. 앱 재시작 뒤 기록의 자동 복원을 보장하지 않습니다.

화면 겹침 수정과 확인 범위는 [학생 화면 처리](./STUDENT_VIEWER_CLIPPING.md), 테마 변경은 [라이트 테마 조정](./LIGHT_THEME_REFINEMENT.md)을 참고합니다.
