# UI 담당 항목 중 엔진 연결을 기다리는 부분 (PR #65·#67)

기준: `feature/client-ui-fix-server`(#65)와 `feature/client-ui-student`(#67)에서 최신 `main`(#73~#75)을 병합한 상태.
UI 담당이 native 엔진을 대신 구현하는 것이 아니라, **엔진이 실제로 막고 있는 항목**과 **엔진 없이 끝낸 UI**를 구분해 기록합니다.
엔진이 없는 기능은 동작하는 것처럼 보이지 않도록 비활성 처리하고 이유를 화면에 표시합니다.

## 엔진과 무관하게 이번 PR에서 끝낸 UI

엔진을 기다리지 않고 구현했습니다.

- 교수자: 세션 이름 입력·접속 코드 표시 제거, `HostNetworkInfoService`의 실제 IP 선택·복사, 포트 5000 기본·고급 설정, 방 비밀번호 사용 여부를 세션 열기 전에 선택(열린 뒤 변경 불가 안내), 작은 기본 접힘 로그, 채팅 선택·복사·Enter/Shift+Enter, 학생 목록 기본 접힘과 갱신 시 펼침 상태 유지, 외부 파일 드롭 등록.
- 학생: 접속 코드 입력·검사 제거, 교수자 IP 입력, 포트 고급 설정, `SecureRoomJoinClient.AuthenticateAsync(host, port, displayName, password, ...)` 호출, 파일명 클릭 다운로드, 채팅 선택·복사.
- 회귀 테스트: 보기 허용 OFF→ON(공유 전/공유 중), 공유 중지·재시작, 퇴장 뒤 복귀 금지.

## 구현 없음과 미검증의 구분

- **구현 없음(엔진 API 부재)**: 위 표의 다섯 항목.
- **장비 부족으로 미검증**: 실제 WDS 다중 PC 공유·재시작, 서로 다른 해상도/DPI와 보조 모니터, 학생 2명 동시 화면. 자동 테스트는 공유 서비스 대역으로만 검증했습니다.
