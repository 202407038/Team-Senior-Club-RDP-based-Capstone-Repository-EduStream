# EduStream 실행용 ZIP 안내

현재 사용자 배포는 **실행용 ZIP만** 제공합니다. v0.1.0-preview.4 (2026-10-07), 앱 코드 main `e75324d` (#94·#95) 기준의 중간 점검용 시험판입니다. 전체 기능 완료 버전이 아닙니다. 과거 회수된 preview.3은 재사용하지 않습니다.

## 다운로드와 실행

1. **[실행용 ZIP 다운로드](https://github.com/202407038/Team-Senior-Club-RDP-based-Capstone-Repository-EduStream/releases/download/v0.1.0-preview.4/EduStream-Portable-win-x64.zip)**를 누릅니다.
2. 받은 ZIP을 우클릭 → **모두 압축 풀기 → 압축 풀기**.
3. `EduStream` 폴더의 **EduStream 교수자.exe / EduStream 학생.exe**를 더블클릭합니다.

Windows x64용 .NET 실행 환경이 포함돼 설치·PowerShell·별도 .NET 설치가 필요하지 않습니다. ZIP 안에서 직접 실행하지 마세요. DLL과 하위 폴더를 지우거나 EXE만 옮기지 말고 폴더 전체를 옮기세요. 바탕화면에는 EXE의 바로가기를 만들 수 있습니다.

GitHub **Code → Download ZIP** 및 Releases의 **Source code (zip)**은 개발용 소스입니다. 실행용 파일명은 `EduStream-Portable-win-x64.zip`입니다. 소스 루트의 `Download-EduStream.url`도 실행용 ZIP으로 연결합니다.

## 앱 실행 후

1. 교수자를 먼저 실행합니다. 같은 Windows 로그인 환경에서 학생이 먼저 켜져 있으면 교수자 실행이 제한됩니다.
2. 교수자는 방 비밀번호 사용 여부를 정하고 **세션 열기**를 누릅니다. 화면에 표시된 교수자 IP를 학생에게 알려줍니다. 공유할 모니터를 고른 뒤 **공유 시작**을 누릅니다.
3. 학생은 처음 열리는 참가 화면에서 이름·교수자 IP·방 비밀번호(있는 경우)를 입력하고 **세션 참여**를 누릅니다. 기본 포트는 5000이며 변경한 경우에만 양쪽 고급 설정에서 바꿉니다. **접속 코드 입력은 없습니다.**
4. 참가 후 강의 화면이 열리고 RDP 초대 비밀번호는 내부 보호 채널로 전달됩니다. 별도 RDP 연결 버튼이나 초대 비밀번호 입력은 필요하지 않습니다.
5. 공유 중지/재시작 시 방 참가는 유지하고 새 초대로 자동 연결을 시도합니다. 학생의 명시적 퇴장/교수자 세션 종료 뒤에는 자동 재참가하지 않습니다. 실제 반복 복귀는 최종 인수가 남아 있습니다.
6. 교수자는 파일 선택/드롭으로 세션 파일을 등록합니다. 학생은 파일 영역에서 파일명 또는 다운로드 버튼으로 받습니다. Windows 다운로드 폴더에 저장하며 등록 해제는 이미 받은 파일을 삭제하지 않습니다.
7. 교수자는 공유 중 **판서 ON**으로 선택 모니터 위에 그립니다. 그림 유지 OFF, 숨김/표시, 전체 지우기, 지우고 OFF를 구분합니다. 도구창 X는 그림을 유지하고 그리기 OFF/도구창 숨김을 수행합니다.
8. 오른쪽 학생 이름을 펼치면 화면 수신을 시도합니다. 여러 목록은 독립적으로 펼치며 큰 보기는 기존 뷰어를 이동합니다. 학생 화면 재노출 방지를 위해 학생 보기를 열면 교수자 공유를 중지합니다. 원격 제어 UI가 있지만 다른 PC 실입력·철회 인수는 아직 완료되지 않았습니다.

다른 PC에서는 호스트 주소에 `127.0.0.1`이 아니라 교수자 PC의 로컬 네트워크 주소를 씁니다. 학생과 교수자는 같은 버전을 사용하세요. 상세 네트워크 조건과 실패 대응은 [실행 가이드](./RUN_GUIDE.md)를 참조합니다.

## 갱신과 정리

- 기존 앱과 강의를 정상 종료한 뒤 새 ZIP을 **새 폴더**에 풉니다. 자동 업데이트는 제공하지 않습니다.
- 받은 강의 자료를 보관한 뒤 이전 실행 폴더를 정리합니다. 실행 파일이 다른 폴더로 옮겨졌다면 직접 만든 바로가기도 새 위치로 변경합니다.
- 새 ZIP을 받았다고 이전 설치형이 자동 제거되지는 않습니다. 과거 설치형을 사용하는 경우 Windows 설정의 설치된 앱에서 EduStream을 제거할 수 있습니다.

## 검증 범위와 주의

- #94/#95 커밋별 추출본 Release 빌드 경고/오류 0. #94 선택 21 통과·native 3 건너뜀, #95 선택 21 통과·native 1 건너뜀. 중복 테스트를 합산한 기능 수가 아니며 이번 전체 회귀는 실행하지 않았습니다.
- ZIP SHA-256: `f1b4adaeddf54f0dc64ef8873147f49fdafa21f7c53c9f4c0f4da54935ccd87c`. sidecar 일치·공백/한글 경로 압축 해제·양 앱 .NET 8.0.31 self-contained 구성·RDP interop 포함을 확인했습니다.
- 해당 압축 해제본 교수자 EXE 실행 후 `EduStream Server` 창 생성까지 확인했습니다. 이후 화면 조작을 중단했으므로 ZIP 학생 앱 시작과 양 앱 실제 조작은 이번 배포에서 확인하지 않았습니다. 실제 다중 PC WDS 화면 복귀·15분 병행·전체 시연 인수도 별도입니다.
- UI·학생 화면 수신·판서 연결과 종료 보완은 포함됐지만, 실제 휠 확대 실패와 큰 보기 최대화 표시 이상은 남아 있습니다.
- 동일 Windows 로그인 환경에서 교수자/학생 WDS 송신을 함께 열면 인증 오류가 재현됩니다. 특히 교수자 공유 시작 후 학생 참가 순서에서 실패했으며, 반대 순서의 한 방향 성공을 양방향 정상으로 보지 않습니다. 별도 PC 검증 전까지 보류합니다. 공유 시작 순간에만 초대를 보내는 구조는 아닙니다.
- 학생 수신 판서 픽셀, 다른 PC 실제 키보드/마우스 제어·회수, 반복 연결·다중 DPI·15분 병행·전체 시연은 미인수입니다. [잔여 작업](./STATUS_AND_ROADMAP.md)을 확인하세요.
- Windows WDS/COM 지원은 별도 OS 조건이며 .NET 포함만으로 보장되지 않습니다.
- 코드 서명은 미적용입니다. 공식 Releases의 파일/해시를 확인하고 조직 정책 차단 시 관리자에게 문의하세요. 백신/방화벽 전체 해제나 정책 우회는 하지 마세요.

## 개발자: 배포 순서

**담당 작업 반영 → 보완·통합 → 빌드/테스트 → ZIP 생성·실행 검증·GitHub 배포 → README/바로가기/실행 안내와 로드맵·진척 최종 갱신** 순서를 따릅니다. 문서 오타 수정마다 앱을 재배포하라는 뜻은 아닙니다. 실행 코드 SHA, 배포 버전, 검증 범위를 기록하고 ZIP 배포 전에는 전체 업데이트 완료로 표시하지 않습니다.

```powershell
./scripts/Build-EduStreamPortable.ps1 -OutputDirectory "$PWD/artifacts/portable/new-build"
./scripts/Test-EduStreamPortable.ps1 -ZipPath "$PWD/artifacts/portable/new-build/EduStream-Portable-win-x64.zip"
```

빌드 PC만 .NET SDK가 필요합니다. 두 self-contained 게시 결과에서 같은 경로의 내용이 다르면 중단하며 덮어쓰지 않습니다. ZIP과 `.zip.sha256`만 Releases에 배포하고 중간 payload/바이너리는 Git에 커밋하지 않습니다. 과거 설치형 제작 스크립트는 이력 보존용이며 신규 배포 대상이 아닙니다.
