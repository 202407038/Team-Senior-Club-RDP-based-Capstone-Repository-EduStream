# 라이트 테마 후속 조정

## 변경 범위

- 라이트 테마의 배경·입력·목록·학생 카드에서 베이지 기운을 줄이고 중립적인 흰색과 연회색을 사용합니다.
- 기본 배경은 `#FAFAFA`, 카드 표면은 `#FFFFFF`이며 영역 구분을 위한 테두리와 강조색은 유지합니다.
- 다크 테마와 수신 영상의 색상은 변경하지 않습니다.

## 검증 기준

- `AppThemePaletteTests`: 변경한 9개 색상과 RGB 중립성, 라이트·다크 글자 대비를 검사합니다.
- Release 솔루션 빌드와 해당 테스트를 PR별로 확인합니다. 실행 화면 확인과 색상 수치 검사는 서로 다른 검증입니다.
- 로컬 확인용 앱에서 적용된 화면을 확인했습니다. 최초 PR 작성 시 ZIP은 갱신하지 않았으며, 이후 병합·배포를 거쳐 정식 v1.1.0 역할별 ZIP에 반영했습니다.

실제 명단, 팜플렛 및 촬영용 실행기는 포함하지 않습니다.
