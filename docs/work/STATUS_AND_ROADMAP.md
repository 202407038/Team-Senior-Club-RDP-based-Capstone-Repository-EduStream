# 현재 상태와 로드맵

이 문서는 작업자가 현재 구현 상태와 이번 주 목표를 빠르게 확인하기 위한 공용 작업 문서입니다.

기준 자료:

- [졸작 중간발표 자료](../reference/presentations/졸작중간발표.pptx)
- [전체 주차별 로드맵](./FULL_WEEKLY_ROADMAP.md)

## 운영 규칙

- 월간 로드맵은 현재 달과 다음 달까지만 유지합니다.
- 전체 주차별 원본 계획은 `FULL_WEEKLY_ROADMAP.md`에서 관리합니다.
- 주차별 계획은 일차별로 나누지 않고, 팀 목표치와 담당별 목표치만 관리합니다.
- 완료된 항목은 문장 끝에 `----- %완료%`를 붙여 표시합니다.
- 자동 테스트와 수동 검증을 구분하며, 자동 테스트만 끝난 항목은 수동 검증까지 완료로 표시하지 않습니다.
- 지난 주차에서 끝내지 못한 항목은 다음 주차 목표에 포함합니다.
- 매주 수요일 기준으로 main 반영 상태, PR 상태, 빌드/테스트 결과를 갱신합니다.
- PR은 역할별로 분리하고, main 반영 전 `dotnet build EduStream.sln`과 `dotnet test EduStream.sln --no-build` 결과를 확인합니다.

## 8월 2주차 점검 현황 (2026-08-10)

- 작업 기준은 `new-origin/main`이며, 현재 main은 `1467a5a`입니다.
- PR #23, #24, #25, #26까지 main에 반영되었습니다.
- PR #23은 한 연결의 서버 예외가 나머지 참가자와 채팅 흐름을 끊지 않는 회귀 테스트를 추가했습니다.
- PR #24는 다중 클라이언트 파일 잠금, 대용량 파일 처리 중 UI 멈춤, 0바이트 파일 처리 흐름을 보강했습니다.
- PR #25는 1번 공통 코어 / 프로토콜의 8월 1~4주차 상태 전환, 오류 매핑, 진행률 계약, 회귀 테스트를 반영했습니다.
- PR #26은 4번 파일 전송의 8월 1~4주차 파일 검증, 실패 후 재시도, 크기별 전송, 대용량·동시 전송 테스트를 반영했습니다.
- main 기준 `dotnet build EduStream.sln`은 경고 0개, 오류 0개로 성공했습니다.
- main 기준 `dotnet test EduStream.sln --no-build`는 103개 전체 통과했습니다.
- 2026-08-10 기준 열린 PR은 없습니다.
- 1번과 4번은 자동 테스트 기준으로 8월 1~4주차 담당 목표를 선행 완료했습니다.
- 팀 전체 중간 통합 테스트 1·2차, 교수자 1명·수강생 2명 수동 실행, 15분 장시간 실행 기록은 아직 완료로 표시하지 않습니다.
- `docs/work/_backup/`은 로컬 백업으로 유지하고 PR에는 포함하지 않습니다.

## 목표 기간 가능성 점검

현재 로드맵의 최종 완료 기준은 2026-11-01입니다. 2026-08-10 기준 약 12주가 남아 있어 일정 구조상 완료는 가능하지만, 8월 팀 통합 검증이 계획대로 진행되어야 합니다.

### 현재 유리한 점

- 1번과 4번의 8월 1~4주차 자동 검증 범위가 PR #25와 #26으로 main에 선행 반영되었습니다.
- 공통 상태 전환, 사용자 오류 메시지, 재시도 가능 여부를 `Core` 기준으로 확인할 수 있습니다.
- 파일 수신 실패 후 동일 전송 재시도와 0바이트·청크 경계·8MB·동시 전송 회귀 기준이 있습니다.
- 한 연결의 서버 예외가 전체 세션을 끊지 않는 다중 참가자 회귀 테스트가 PR #23으로 추가되었습니다.
- main 자동 테스트 103개가 통과해 8월 중간 통합 테스트의 코드 기준선이 확보되었습니다.

### 현재 위험 요소

- 2번, 3번, 5번의 8월 상태 관리·복구 흐름 결과는 역할별 PR 또는 검증 기록으로 추가 확인해야 합니다.
- 클라이언트 `ScreenRenderer`의 실제 이미지 프리뷰와 화면 품질에 대한 수동 기록이 없습니다.
- 교수자 1명·수강생 2명 기준 수동 통합 실행과 15분 이상 장시간 실행 기록이 없습니다.
- 화면, 파일, 채팅 상태가 동시에 바뀔 때 UI 표시 우선순위와 시연 기준 문구가 확정되지 않았습니다.
- 최종보고서, 발표 시나리오, 테스트 결과 기록, 화면 캡처 자료는 후반 산출물로 남아 있습니다.

### 일정 유지 조건

- 2026-08-16까지 2번·3번·5번의 8월 1~2주차 결과와 7월 이월 항목의 처리 상태를 확인합니다.
- 2026-08-23까지 대표 사용자 시나리오 중간 통합 테스트 1차와 발견 결함 목록을 기록합니다.
- 2026-08-30까지 중간 통합 테스트 2차를 완료하고 치명 오류를 제거합니다.
- 2026-09-27까지 실제 사용자 시나리오와 회귀 테스트 기준을 확정합니다.
- 2026-10-05부터 새 기능 추가를 제한하고 QA, 문서, 시연 준비로 전환합니다.
- 8월 3주차까지 수동 통합 기록이 없으면 RDP 보조 기능과 추가 대용량 범위를 우선순위에서 낮춥니다.

현재 판단은 **조건부 일정 유지 가능**입니다. 1번과 4번은 계획보다 앞서 있지만, 팀 전체 목표는 2번·3번·5번의 상태 관리와 수동 통합 결과가 8월 안에 확인되어야 유지됩니다.
