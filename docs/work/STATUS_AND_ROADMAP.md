# 현재 상태와 로드맵

이 문서는 작업자가 현재 구현 상태와 이번 주 목표를 빠르게 확인하기 위한 공용 작업 문서입니다.

기준 자료:

- [졸작 중간발표 자료](../reference/presentations/졸작중간발표.pptx)
- [전체 주차별 로드맵](./FULL_WEEKLY_ROADMAP.md)

## 운영 규칙

- 월간 로드맵은 현재 달과 다음 달까지만 유지합니다.
- 전체 주차별 원본 계획은 `FULL_WEEKLY_ROADMAP.md`에서 관리합니다.
- 주차별 계획은 일차별로 나누지 않고, 팀 목표치와 담당별 목표치만 관리합니다.
- 완료된 항목은 문장 끝에 `----- %완료%`를 붙여 표시합니다.
- 자동 테스트와 수동 검증을 구분하며, 자동 테스트만 끝난 항목은 수동 검증까지 완료로 표시하지 않습니다.
- 지난 주차에서 끝내지 못한 항목은 다음 주차 목표에 포함합니다.
- 매주 수요일 기준으로 main 반영 상태, PR 상태, 빌드/테스트 결과를 갱신합니다.
- PR은 역할별로 분리하고, main 반영 전 `dotnet build EduStream.sln`과 `dotnet test EduStream.sln --no-build` 결과를 확인합니다.

## 목표 기간 가능성 점검

현재 로드맵의 최종 완료 기준은 2026-11-01입니다. 2026-07-20 기준 약 15주가 남아 있어 일정 구조상 완료는 가능하지만, 아래 중간 마감 조건을 지켜야 합니다.

### 현재 유리한 점

- 1번과 4번은 7월 3~4주차 목표를 main에 반영했습니다.
- 공통 상태 모델은 8월 1주차 작업 일부를 선행했습니다.
- 실패 후 동일 세션 재전송 검증은 8월 2주차 작업 일부를 선행했습니다.
- 화면 공유 중 파일 전송과 채팅을 함께 실행하는 자동 통합 기준선이 있습니다.
- 8월 안정화, 9월 고도화, 10월 기능 동결·QA로 이어지는 완충 구간이 남아 있습니다.

### 현재 위험 요소

- 2번, 3번, 5번의 7월 3~4주차 담당 결과가 별도 PR 또는 수동 검증 기록으로 확인되지 않았습니다.
- 클라이언트 `ScreenRenderer`는 실제 이미지 프리뷰보다 화면 패킷 상태 문자열 표시 중심입니다.
- 15분 이상 자동 화면 공유와 교수자 1명·수강생 2명 기준 수동 통합 기록이 없습니다.
- 화면, 파일, 채팅 상태가 동시에 바뀔 때 UI 표시 우선순위가 확정되지 않았습니다.
- 최종보고서, 발표 시나리오, 테스트 결과 기록, 화면 캡처 자료는 후반 산출물로 남아 있습니다.

### 일정 유지 조건

- 2026-08-02까지 7월 이월 작업, 실제 이미지 프리뷰, UI 상태 우선순위, 15분 실행 검증을 정리합니다.
- 2026-08-30까지 중간 통합 테스트 1차와 2차를 완료하고 치명 오류를 제거합니다.
- 2026-09-27까지 실제 사용자 시나리오와 회귀 테스트 기준을 확정합니다.
- 2026-10-05부터 새 기능 추가를 제한하고 QA, 문서, 시연 준비로 전환합니다.
- 중간 마감이 1주 이상 밀리면 RDP 보조 기능과 대용량 파일 같은 확장 범위를 우선순위에서 낮춥니다.

현재 판단은 **조건부 일정 유지 가능**입니다. 1번과 4번은 계획보다 앞서 있지만, 팀 전체 목표는 2번·3번·5번의 이월 항목을 8월 2일까지 닫아야 유지됩니다.
