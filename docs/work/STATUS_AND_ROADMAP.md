# 현재 상태와 로드맵

이 문서는 작업자가 현재 구현 상태와 이번 주 목표를 빠르게 확인하기 위한 공용 작업 문서입니다.

기준 자료:

- [졸작 중간발표 자료](../reference/presentations/졸작중간발표.pptx)

## 운영 규칙

- 월간 로드맵은 현재 달과 다음 달까지만 유지합니다.
- 지난 달 목표는 완료 여부를 정리한 뒤 필요하면 작업 기록 문서로 옮깁니다.
- 주차별 계획은 일차별로 나누지 않고, 팀 목표치와 담당별 목표치만 관리합니다.
- 완료된 항목은 `~~내용~~ 완료` 형식으로 표시합니다.
- 주차가 바뀌면 완료 항목을 갱신하고 다음 주 목표치를 조정합니다.

- join / leave / disconnect 흐름 안정성 확인
- 다중 클라이언트 접속 시 참가자 수와 로그 갱신 확인

##### 3. 화면 송신

- 화면 캡처와 송신 루프가 시연 가능한 수준인지 확인

##### 4. 파일 전송

- ~~chunk 분할, checksum, metadata mismatch 테스트 유지~~ 완료
- UI 연결에 필요한 상태값과 메시지 정리

##### 5. 클라이언트 UI / 수신

- 세션/채팅/파일/화면 상태가 한 화면에서 읽히는지 확인

### 6월 1주차

#### 팀 목표치

- 세션/채팅/파일/화면 흐름을 하나의 시연 시나리오로 연결
- 다중 클라이언트 기준 최소 테스트 진행
- 파일 전송 UI 상태 표시 보강
- 화면 공유 수신 상태 확인
- README / docs / PPT 내용 동기화

#### 담당별 목표치

##### 1. 공통 코어 / 프로토콜

- 시연 중 발생 가능한 ErrorCode / AckCode 부족 여부 확인
- 공통 패킷 검증 규칙과 실제 사용 흐름 비교

##### 2. 서버 세션 / 네트워크

- 교수자 세션 open 이후 수강생 2명 이상 접속 흐름 확인
- 비정상 disconnect 이후 참가자 목록 정리 확인

##### 3. 화면 송신

- 화면 송신 시작/중지 흐름 확인
- 클라이언트에서 프레임 수신 상태가 갱신되는지 확인

##### 4. 파일 전송

- 실제 파일 선택 후 전송 흐름 확인
- 실패 케이스가 UI 또는 로그에 구분되어 남는지 확인

##### 5. 클라이언트 UI / 수신

- 수강생 기준으로 현재 연결 상태가 명확히 보이는지 확인
- 파일 수신 완료/실패 상태 메시지 정리
