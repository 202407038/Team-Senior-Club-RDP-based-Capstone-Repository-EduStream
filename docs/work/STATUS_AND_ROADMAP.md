# 현재 상태와 로드맵

이 문서는 작업자가 현재 구현 상태와 이번 주 목표를 빠르게 확인하기 위한 공용 작업 문서입니다.

기준 자료:

- [졸작 중간발표 자료](../reference/presentations/졸작중간발표.pptx)

## 운영 규칙

- 월간 로드맵은 현재 달과 다음 달까지만 유지합니다.
- 주차별 계획은 일차별로 나누지 않고, 팀 목표치와 담당별 목표치만 관리합니다.
- 완료된 항목은 문장 끝에 `----- %완료%`를 붙여 표시합니다.
- 지난 주차에서 끝내지 못한 항목은 지난 주차에 이월 문구를 남기지 않고 다음 주차 목표에 포함합니다.
- 매주 수요일 기준으로 main 반영 상태, PR 상태, 빌드/테스트 결과를 갱신합니다.
- PR은 역할별로 분리하고, main 반영 전 `dotnet build EduStream.sln`과 `dotnet test EduStream.sln --no-build` 결과를 확인합니다.

## 월간 로드맵

현재 6월 마지막 주차에 진입했으므로, 이 문서에는 6월 마감 기준과 다음 달인 7월 작업 기준을 함께 표시합니다.

### 6월 목표: 기반 구축 마감과 핵심 엔진 진입 준비

- 공통 패킷 / 직렬화 / 검증 규칙 기준선 확정
- 세션 관리 기초 흐름 main 반영 상태 확인
- 기초 UI와 로깅 시스템 main 반영 상태 확인
- 역할별 담당 범위와 PR 기준선 정리
- 7월 화면 캡처 엔진 작업에 필요한 연결 지점 확인

### 7월 목표: 화면 캡처 엔진과 송수신 흐름 고도화

- 화면 캡처 서비스와 송신 루프 품질 보강
- 서버 화면 송신 상태와 클라이언트 수신 상태 연결
- TCP 송수신 흐름의 예외 처리와 로그 보강
- 화면 / 채팅 / 파일 상태가 한 화면에서 읽히도록 UI 확인
- 8월 통합 테스트를 위한 시연 흐름 초안 구성

#### 담당별 목표치

##### 1. 공통 코어 / 프로토콜

- 화면 / 파일 / 채팅 payload 길이 검증 규칙 재확인

- 화면 송신 중 disconnect 발생 시 세션 정리 흐름 확인

- 화면 프레임 크기와 송신 간격 기준값 점검

##### 4. 파일 전송

- 화면 송신 중 파일 전송을 순차 실행하는 흐름 검증
- 파일 전송 실패 메시지가 세션 / 화면 상태와 섞이지 않는지 확인
- 청크 전송 상태와 수신 진행률 갱신 흐름 재확인
- checksum / metadata mismatch 실패 로그 문구 정리
- 파일 전송 완료 후 같은 세션에서 추가 전송 가능 여부 확인

##### 5. 클라이언트 UI / 수신

- 화면 / 파일 / 채팅 수신 상태 문구 구분 확인

- 세션 연결 상태와 기능별 수신 상태가 동시에 보이는지 확인

- 잘못된 PacketType / AckCode / ErrorCode 처리 기준 테스트 추가
- 송수신 실패 시 공통 예외 메시지 형식 정리

- 네트워크 예외 발생 시 UI로 전달할 상태값 확인

##### 3. 화면 송신

- 다중 클라이언트 기준 화면 프레임 송신 흐름 확인
- 화면 송신 시작 전 세션 상태 검증 흐름 보강
- 화면 공유 중지 요청 후 루프 종료와 상태 메시지 확인
- 연속 프레임 송신 중 실패 프레임 처리 기준 확인
- 화면 송신 로그가 파일 / 채팅 로그와 구분되는지 확인

##### 4. 파일 전송

- 다중 클라이언트 기준 파일 패킷 브로드캐스트 흐름 확인
- 파일 전송 중 disconnect 발생 시 임시 파일 정리 흐름 검증
- 수신 실패 후 재전송 가능 여부 확인
- 파일 전송 상태 메시지가 UI에 전달되는 흐름 점검
- 중형 파일 전송 기준 build/test 또는 수동 검증 기록 정리

##### 5. 클라이언트 UI / 수신

- 여러 상태 변화가 동시에 발생할 때 UI 문구가 덮어쓰이지 않는지 확인
- 화면 수신 상태와 파일 수신 상태를 독립적으로 표시
- disconnect / reconnect 상황에서 상태 문구 초기화 여부 확인
- 수신 오류 발생 시 사용자에게 보이는 메시지 보강
- 시연 기준으로 버튼 활성 / 비활성 상태 확인
