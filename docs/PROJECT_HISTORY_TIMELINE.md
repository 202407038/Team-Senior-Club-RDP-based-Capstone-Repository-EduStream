## 2. 파트별 누적 요약

### 문서/협업

- 프로젝트 README 정비, 문서 허브 구성, UML 관리 기준 수립
- 팀 개발 가이드, 아키텍처 가이드, 구현 플레이북 작성
- 사용자 워크플로우 시나리오와 7일 스프린트 구현 가이드 확장
- 브랜치/PR/동기화 규칙과 역할 분담 기준을 문서화

### 구조/기반

- `.NET 8` 기준 솔루션과 `Server / Client / Core` 프로젝트 구성
- WPF 기반 서버/클라이언트 실행 구조 정리
- UML 기반 스켈레톤 코드 반영

### 코어/프로토콜

- 공통 패킷 계약과 프로토콜 기초 구조 정립
- 공통 헬퍼, 파일 전송 규칙, 화면 패킷 검증 규칙 추가
- `PacketFactory`, 화면 캡처 설정, 공통 응답/검증 규칙 확장

### 세션/네트워크

- `SessionManager` 흐름 보강
- `TcpServerService`, `TcpClientService`, `HeartbeatService` 도입
- 실제 join/leave, 연결 정리, TCP 수신/송신 흐름 통합

### 채팅

- 양방향 채팅 흐름 연결
- 직렬화 버그 수정
- 비참가자 차단, 빈 메시지 차단, 메시지 길이 제한, 송신자 검증 강화
- 입장/퇴장/세션 종료 시 시스템 알림 브로드캐스트 추가

### 파일 전송

- 파일 청크 수신 버퍼 스켈레톤 추가
- 청크 분배, 조립, 체크섬 검증, 저장 흐름 구현
- 경계값 검증, 실패 모델, pending 상태 처리 보강
- 반복/실패 테스트 프로젝트 추가

### 화면 송신/RDP

- 화면 패킷 메타데이터 규칙과 PNG 프리뷰 캡처 추가
- 서버 화면 브로드캐스트 검증
- WPF 기반 RDP 프리뷰 연동
- 재사용 가능한 화면 공유 서비스와 연속 송신 루프 추가

### 클라이언트 UI

- 세션/채팅 레이아웃 정비
- 파일/화면 수신 상태 패널 추가
- 실시간 수신 흐름에 맞는 상태 표시 정렬

### 테스트/검증

- 파일 수신 반복/실패 테스트 추가
- 패킷 팩토리 테스트 추가
- 파일 분배 청크 테스트와 데모 검증 경로 보강

### 3단계. 네트워크와 실기능 연결

- 세션 join/leave와 heartbeat 흐름 연결

- 화면 프리뷰, RDP 프리뷰, 화면 공유 서비스 확장
