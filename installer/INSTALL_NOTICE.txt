EduStream 시험 배포판

Windows x64용 강의 보조 앱입니다. 다음 화면에서 학생용, 교수자용, 둘 다 중 하나를 선택하세요.
설치 후 시작 메뉴 또는 바탕화면의 EduStream 아이콘으로 실행합니다. PowerShell, 소스 코드, 별도 .NET 설치는 필요하지 않습니다.

교수자: 세션 열기 → WDS 공유 시작.
학생: 설정에서 이름/교수자 주소/포트 입력 → 세션 참여 → 별도로 받은 초대 비밀번호 입력 → RDP 연결.

현재는 시험 배포 단계입니다. 실제 다중 PC의 화면 품질/네트워크 환경과 장시간 사용 검수는 진행 중입니다.
RDP 공유에는 Windows WDS/COM 지원이 필요합니다. .NET 포함 설치가 OS 구성 지원까지 보장하지는 않습니다.
방화벽을 전체 해제하거나 인터넷에 공유 포트를 개방하지 마세요. 초대 비밀번호를 공용 채팅에 보내지 마세요.

제거: Windows 설정 → 앱 → 설치된 앱 → EduStream → 제거.
다운로드한 강의 파일은 제거 대상에 포함되지 않습니다.
