EduStream 실행용 ZIP · Windows x64 시험판

1. ZIP을 마우스 오른쪽 버튼으로 눌러 '모두 압축 풀기'를 선택합니다.
2. 압축을 푼 EduStream 폴더에서 사용할 역할을 더블클릭합니다.
   교수자: EduStream 교수자.exe
   학생:   EduStream 학생.exe

설치, PowerShell 명령, 별도 .NET 설치는 필요하지 않습니다.
ZIP 안에서 바로 실행하지 말고 반드시 전체 압축을 풀어주세요.
옆의 DLL과 하위 폴더는 실행에 필요하므로 삭제하지 마세요.
EXE만 따로 옮기지 말고 EduStream 폴더 전체를 옮기세요.
바탕화면에 놓고 싶다면 EXE의 바로가기를 만들어 사용하세요.

교수자를 먼저 실행하고 방 비밀번호 사용 여부를 정한 뒤 '세션 열기'를 누릅니다.
학생은 첫 참가 화면에서 학생 이름/교수자 PC IP/방 비밀번호(설정한 경우)를 입력합니다.
기본 포트는 5000이며 변경한 경우에만 양쪽 고급 설정에서 같은 포트를 입력합니다.
접속 코드와 별도의 RDP 초대 비밀번호 입력은 필요하지 않습니다.
교수자는 공유할 모니터를 고른 뒤 '공유 시작'을 누릅니다. 공유 중 모니터는 바꿀 수 없습니다.
교수자 공유 재시작 시 학생은 새 초대로 자동 연결을 시도합니다.
학생이 연결 종료로 방을 나가거나 교수자가 세션을 닫으면 자동 재참가하지 않습니다.
다른 PC의 교수자에게 접속할 때 127.0.0.1을 사용하지 않습니다.

교수자 파일 선택/드롭 → 등록 버튼 → 강의 파일 목록 등록, 학생 파일 영역 → 강의 파일 → 다운로드를
사용하면 Windows 다운로드 폴더에 저장합니다. 등록 해제는 이후 다운로드를 막으며
이미 저장한 학생 파일은 삭제하지 않습니다. 즉시 전송 파일도 다운로드 폴더에 저장하며
기존 같은 이름 파일은 보존하고 새 파일 이름에 번호를 붙입니다.
드래그는 파일 선택만 준비합니다. 한 파일씩 처리하며 여러 파일/폴더를 놓으면 안내합니다.
같은 Windows 로그인 세션에서는 학생을 먼저 실행하면 교수자 실행이 제한됩니다.

이 배포는 v0.1.0-preview.7 (2026-10-14) 파일 피드백 반영 시험판입니다.
앱 코드 기준: main 04dd114 (#97, #98, #99 반영).
preview.3은 과거 회수된 버전이므로 재사용하지 않습니다.
교수자 판서, 학생별 화면 보기/큰 보기/제어 UI, 학생 자동 공유 연결이 포함되지만
전체 기능 인수 완료 버전은 아닙니다. 판서 도구 X는 그림을 유지하고 도구창을 닫습니다.

검증 범위와 주의:
- 앱 코드 자동 테스트: 918개 통과, 52개 생략, 실패 0개.
- 사용자가 기존 실행 재확인을 완료했다고 알려준 결과와 자동 검증은 구분합니다.
- 이번 파일 변경의 직접 UI 드래그 및 다중 PC 검증을 자동 테스트 완료로 표시하지 않습니다.
- 휠 확대/축소는 사용자 요청으로 이번 수정에서 제외했으며 정상 동작을 보장하지 않습니다.
- 합의된 UI 간소화로 학생 허용 토글·즉시 제어 중단 버튼·로그 영역은 제거됐습니다.
  학생 화면 보기·제어 허용은 기본 ON이며, 세션 나가기는 유지합니다.
- 한 PC의 같은 Windows 로그인 환경에서 교수자/학생 송신을 함께 열면,
  특히 교수자가 먼저 공유하고 학생이 참가한 순서에서 인증/복호화 오류가 재현됐습니다.
  반대 순서의 한 방향 연결 성공을 양방향 동시 정상 동작으로 해석하지 마세요.
  WDS 송신 세션 하나/로그인 환경 제약이 있으므로 실제 양방향 검증은 서로 다른 PC가 필요합니다.
- 학생 화면을 열어도 교수자 공유를 자동으로 중지하지 않습니다.
  캡처 제외 설정 실패 시 안내하며, 해당 창을 공유하지 않는 모니터로 옮겨 주세요.
  API 성공만으로 모든 환경의 재공유 방지를 보장하지 않습니다.
- 초대 제한 50은 실측으로 검증된 동시 수용 인원이 아닙니다.
- 학생 수신 화면의 판서, 다른 PC 실제 키보드/마우스 제어와 회수, 반복 재접속,
  다중 학생/다중 DPI/15분 병행/전체 시연은 최종 확인이 남아 있습니다.
빌드/선택 테스트와 ZIP 시작 검증은 위 기능의 실환경 완료를 뜻하지 않습니다.

업데이트는 실행 앱을 종료한 뒤 새 ZIP을 새 폴더에 압축 해제합니다.
수신한 강의 자료를 확인하고 보관한 뒤 이전 앱 폴더를 정리하세요.
이 배포는 자동 업데이트와 설치 등록/자동 바탕화면 아이콘 생성을 하지 않습니다.

Windows WDS/COM 지원과 네트워크 연결 조건은 별도입니다.
다중 PC RDP 실사용 인수는 진행 중이며 이 ZIP 검증은 전체 시연 완료를 뜻하지 않습니다.
코드 서명 미적용으로 Windows 보안 경고가 표시될 수 있습니다.
